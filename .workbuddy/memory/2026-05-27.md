## 踩坑（已记录在专家包外的工程经验里，下次直接复用）
- JSON 内 `comment` / `report` 字段里的 markdown 引用片段「...」如果含未转义的 ASCII `"`，会直接导致 JSON 解析失败。**写产物时所有 markdown 内的中文双引号一律用 “/”、‘/’ 或 『』 替代 ASCII `"`**，避免反复修。
- lint-outbox 期望的字段名是 `dimensionId` 而不是 `id`（rubric 与 extraDimensions 都是），契约 §3.0 顶层结构示例里写的是 `id` 但 lint 要的是 `dimensionId`，**这里有契约示例与 lint 实现不一致**。下次直接用 `dimensionId`。
- extraDimensions 即使 `activated=false` 也必须有 `scores: []` 字段（`必须是数组` 校验）。
